# Razor Portfolio

## Preview locally
1. Extract the project folder.
2. Open `index.html` in your browser, or open the folder in Visual Studio Code and use Live Server.

## Publish updates to GitHub Pages
1. Open your `razor-portfolio` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload the contents of this folder, replacing the older files when prompted.
4. Commit the changes. GitHub Pages will publish the update automatically.

## Music picker
The welcome screen offers a searchable list of songs and plays short previews returned by the iTunes Search API. Preview availability varies by song and region; it does not provide full tracks. Visitors must press **Enter site** to start playback. The floating player lets them pause, resume, stop, or choose another preview.

## Editing
- `index.html`, `about.html`, `skills.html`, `contact.html`: page content
- `style.css`: colors, layout, and styling
- `script.js`: navigation and music picker behavior
