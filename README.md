# Razor Portfolio

A clean, dark portfolio site for Razor. Built with HTML, CSS, and JavaScript.

## Preview it
1. Extract this folder.
2. Double-click `index.html` to open it in a browser, or open the folder in Visual Studio Code and use Live Server.

## Publish updates to GitHub Pages
1. Open `https://github.com/itsjusrazor1/razor-portfolio`.
2. Choose **Add file → Upload files**.
3. Upload the contents of this folder into the repository root (not the outer folder).
4. Commit the changes. GitHub Pages will publish the update.

## Music picker
The welcome screen shows the ten song titles from the playlist screenshot. It looks up short preview clips through Apple's public iTunes Search API. Preview availability depends on the track and region, and some songs may not have a preview. These are not full songs. Visitors must press **Enter site** to start audio because browsers block autoplay. The floating player has play/pause, change-song, and stop controls.

The site does not host or redistribute music files. If you want visitors to hear full songs, use an official music service's supported embed or link instead.
